# Inbox

Dump anything here — one file per thing, any name, any format:

- meeting notes, pasted emails, voice-memo transcripts, ideas, "remind me to…"

Fastest way from your phone: GitHub app → this repo → `inbox/` → add file.

Your Chief of Staff processes everything here on its next run, turns it into
tasks / people notes / drafts, and moves the original to `inbox/processed/`.
