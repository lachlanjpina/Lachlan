# Capture

1. Save the raw text to `inbox/YYYY-MM-DD-HHMM-<slug>.md`.
2. Immediately run `triage-inbox` on just that file.
3. Reply in one line: what you filed and where (e.g. "Added to This week: send
   Acme proposal, due Tue").
4. Commit (`cos: capture <slug>`) and push.
